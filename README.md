# BRAIN — Agence de Communication Digitale, Créative & Audiovisuelle (Abidjan)

Site web corporate premium, moderne et 100% responsive pour **BRAIN**, agence de communication digitale, audiovisuelle, créative et de transformation numérique basée à Abidjan, Côte d'Ivoire.

**Signature :** « Attirer • Convertir • Fidéliser »

## 🎯 Objectif

Positionner BRAIN comme une agence premium, créative et technologique, capable d'accompagner les entreprises de la stratégie jusqu'à la production et la digitalisation — et transformer les visiteurs en prospects qualifiés (demandes de devis).

## 🎨 Direction artistique

- **Style** : premium, corporate, cinématique, technologique, créatif, haut de gamme.
- **Palette** : noir profond, bleu électrique, bleu nuit, orange vif, blanc — reprise directement de l'affiche BRAIN fournie (identité visuelle & branding).
- **Effets** : glow bleu/orange, gradients, glassmorphism léger, animations au scroll, micro-interactions, cartes avec hover premium.
- **Typographies** : Poppins (titres) + Inter (texte courant), via Google Fonts.
- **Icônes** : Font Awesome 6.4.0 (CDN).

- `index.html` — Page d'accueil (hero, 7 expertises, pourquoi BRAIN, approche en 5 étapes, portfolio aperçu, clients, témoignages, offres, CTA final).
- `services.html` — Vue d'ensemble des 7 pôles de services.

- `service-web.html` — Sites Web & E-commerce (détail complet).
- `service-social.html` — Community Management & Réseaux Sociaux (détail complet).
- `service-design.html` — Design Graphique, Print & Contenus (détail complet).
- `service-films.html` — Films Publicitaires & Institutionnels (détail complet).
- `service-live.html` — Captation Vidéo, Reportages & Live (détail complet).
- `service-digital.html` — Digitalisation des Entreprises (détail complet).
- `portfolio.html` — Portfolio avec filtres dynamiques (Tout / Branding / Web / Social Media / Design / Audiovisuel / Événementiel / Digital).

### Composants & interactions
- Header fixe avec effet au scroll + menu hamburger animé (mobile).
- Hero avec badge, titre animé, stats, visuel avec cartes flottantes.
- Cartes de services avec effet hover (image zoom, overlay dégradé bleu/orange).
- Timeline « Notre approche » en 5 étapes (Écouter, Analyser, Concevoir, Produire, Mesurer).
- Portfolio avec système de filtres JavaScript (sans rechargement de page).
- Témoignages, packages tarifaires (Starter / Growth / Premium / Entreprise — sans prix, CTA « Demander un devis »).
- Formulaire de contact avec validation JavaScript (champs requis, format email) + message de succès.
- Boutons flottants : WhatsApp (pulsation), retour en haut.
- Animations au scroll (reveal), compteurs animés (Intersection Observer).
- Design 100% responsive (breakpoints 1080px et 768px), menu mobile plein écran.

### SEO
- Balises titres, meta descriptions et mots-clés uniques par page (ciblant "agence communication Abidjan", "création site web Abidjan", "branding Côte d'Ivoire", "production audiovisuelle Abidjan", etc.).
- Structure Hn sémantique (H1 unique par page, H2/H3 pour les sections).
- Open Graph (og:title, og:description, og:image) sur toutes les pages.
- Données structurées JSON-LD (schema.org/AdvertisingAgency) sur la page d'accueil.
- `sitemap.xml` et `robots.txt` fournis.
- URLs propres et descriptives (`service-branding.html`, `service-web.html`, etc.).

## 🖼️ Médias utilisés

- **Logo officiel BRAIN** intégré dans le header et le footer de toutes les pages (`ASSET/brain-icon.png`, fond transparent, extrait du logo fourni par le client).
- L'affiche BRAIN officielle fournie par le client est intégrée comme visuel principal (hero + service Branding + portfolio) : `ASSET/brain-branding-poster.png`.
- Les visuels illustrant les autres services (web, social media, design, films, live, digitalisation, équipe) proviennent de banques d'images libres de droit (Creative Commons / Domaine public), sélectionnées pour correspondre à l'ambiance premium bleu/orange/noir demandée.
- **Note** : les tentatives de génération d'images IA sur mesure (studio créatif, caméra, dashboard, etc.) ont échoué en raison d'un manque de crédits sur le compte au moment de la création. Le site utilise donc des photos libres de droit en remplacement. Il est possible de régénérer ces visuels plus tard si des crédits sont disponibles, ou de les remplacer par les vraies photos de l'agence BRAIN.

## 🚧 Fonctionnalités non implémentées (limites d'un site statique)

- **Envoi réel des demandes de devis** : le formulaire de contact valide les champs côté client mais ne les transmet à aucun serveur/CRM (aucune API d'envoi n'a été fournie et cela nécessiterait un backend). Il faudrait connecter un service tiers (ex. Formspree, EmailJS, ou une Table API pour stocker les leads) pour recevoir réellement les demandes.
- **Logo officiel BRAIN** : le logo utilisé dans le header/footer est une icône Font Awesome générique (cerveau) en attendant le fichier logo officiel vectoriel. Un emplacement est prévu pour l'intégrer facilement (`.brain-icon`).
- **Vrais témoignages et logos clients** : les cartes témoignages et logos clients sont des emplacements (placeholders) génériques, comme demandé — aucun nom réel n'a été inventé.
- **Prix des offres** : volontairement absents, remplacés par « Demander un devis » comme demandé.
- **Vraies ASSET/vidéos de production BRAIN** : les visuels de service sont des photos libres de droit en attendant les vrais visuels de l'agence.
- **Carte Google Maps** : intégrée en mode générique (recherche "Abidjan, Côte d'Ivoire") faute d'adresse précise fournie.

## 📈 Recommandations pour la suite

1. Fournir de **vraies photos/vidéos** des réalisations (branding, tournages, événements) pour remplacer les visuels libres de droit.
3. Connecter le formulaire de contact à un service d'envoi d'email (EmailJS/Formspree) ou à la Table API du projet pour stocker les leads.

5. Ajouter une adresse précise à Abidjan pour affiner la carte.
6. Envisager un blog/actualités pour renforcer le SEO sur les mots-clés ciblés.
7. Une fois prêt, publier via l'onglet **Publish** du projet.
