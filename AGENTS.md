# AGENTS.md — BRAIN (Abidjan, Côte d'Ivoire)

Instructions permanentes pour toute session sur le projet BRAIN, agence de communication digitale, créative & audiovisuelle basée à Abidjan.

## Directive visuelle absolue — Personnages

Lorsqu'un visuel contient un ou plusieurs personnages humains, **TOUS les personnages doivent obligatoirement être des personnes africaines noires à la peau noire**.

Cette règle s'applique à :

* l'image principale de chaque article ;
* toutes les images secondaires ;
* les illustrations ;
* les scènes professionnelles ;
* les scènes de bureau ;
* les scènes marketing ;
* les scènes audiovisuelles ;
* les scènes technologiques ;
* les scènes d'entreprise ;
* les visuels générés ultérieurement pour le blog.

### Apparence des personnages

Les personnages doivent présenter une apparence africaine noire crédible et naturelle :

* peau noire ;
* traits africains naturels ;
* cheveux afro, locks, tresses, cheveux courts ou coiffures adaptées ;
* diversité des morphologies ;
* hommes et femmes africains ;
* professionnels africains contemporains ;
* vêtements professionnels modernes ;
* apparence réaliste et naturelle.

Lorsque le contexte est ivoirien, privilégier une représentation visuelle cohérente avec la diversité de la population ivoirienne.

### Interdictions

NE PAS générer :

* personnages blancs ;
* personnages européens ;
* personnages nord-américains blancs ;
* personnages asiatiques ;
* personnages latino-américains ;
* personnages à peau claire non cohérents avec la consigne ;
* personnages métissés lorsque leur apparence ne correspond pas à la représentation africaine noire demandée.

NE PAS remplacer la consigne par une simple mention "African-inspired".

Le personnage doit être **visiblement et clairement une personne africaine noire à la peau noire**.

### Consigne à ajouter à chaque prompt image

Chaque prompt d'image destiné à l'IA doit contenir une formulation équivalente à :

"All human subjects must be Black African people with naturally dark Black skin and authentic African facial features. No white people, no European-looking people, no Asian people, no Latino-looking people. The characters must look like contemporary Black African professionals."

Pour les scènes ivoiriennes, ajouter :

"Authentic contemporary Côte d'Ivoire / Abidjan setting, with Black African people representative of the local professional environment."

### Règle de contrôle

Après génération de chaque prompt, vérifier que la description impose explicitement :

1. Black African people ;
2. naturally dark Black skin ;
3. authentic African facial features ;
4. contemporary African professional appearance ;
5. Côte d'Ivoire / Abidjan lorsque le contexte l'exige.

Si un personnage est présent mais que son origine africaine noire n'est pas explicitement définie dans le prompt, **corriger le prompt avant de le sauvegarder**.

Cette règle est prioritaire pour tous les visuels du blog.
